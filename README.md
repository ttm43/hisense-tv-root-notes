# 旧电视已 Root，遥控器按键也能自己改了 📺

一台海信 Hisense 65N7，原装遥控器坏了，换来的万能遥控器又没有能直接回主页的 Home 键。

折腾了一圈，通过 Wi-Fi 拿到了电视 Linux 系统的 Root 权限。现在可以自己改遥控器按钮的功能。

最实用的一改：**把 MEDIA 键改成 Home，按一下直接回主页。** 不用再先进媒体界面、再按返回了。

顺手也加上了开机、待机唤醒后回主页的逻辑。旧电视继续用。

## 这次做到了什么

- 通过现有 Wi-Fi 通道执行 Root 命令。
- 修改电视端按键映射，让遥控器上的 MEDIA 键直接打开 Home。
- 将修改保存到电视，保留原文件备份。
- 添加启动、唤醒后进入主页的逻辑。

MEDIA 一键回主页已实际验证；启动逻辑已保存，具体唤醒方式的覆盖情况没有逐项测试。
